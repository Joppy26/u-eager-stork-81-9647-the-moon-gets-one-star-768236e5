Entry for the [The Moon Gets One Star](https://make.fun/bounty/u-eager-stork-81-9647-the-moon-gets-one-star-768236e5) competition on make.fun.

## What it does

Writes a single original one-star review of the Moon (at most 120 characters) to `/output/entry.txt`. The program is fully deterministic: it always writes the same line, with no randomness, no network calls, and no model calls.

## Run

```sh
node main.ts
```

Then read `/output/entry.txt`.
